照片去水印工具 · 免安装版
====================================

【怎么用】
1. 双击「照片去水印.exe」
2. 把照片拖进窗口（或点「打开照片…」）
3. 点「识别并标红水印」→ 检查红色区域（多涂的用橡皮擦、漏的用画笔补）
4. 点「开始去水印」
5. 点「保存结果…」

【重要】
· 必须把 models 文件夹和 exe 放在一起，AI 修复才能用。
· 首次启动会解压运行库，可能要等几秒，属正常现象。
· 全部处理在本机完成，不联网、不上传任何图片。

【操作】
左键涂抹 / 右键单击切换画笔橡皮 / 右键拖动平移 / 滚轮缩放
按住空格 对比原图 / Ctrl+Z 撤销一笔 / Esc 清空 / [ ] 调画笔大小

【环境要求】
Windows 7 SP1 / 10 / 11，64 位系统。无需安装 Python，无需管理员权限。
（32 位系统请告知，需要单独打 32 位版本）

【文件】
照片去水印.exe        主程序
models\lama_fp32.onnx  AI 修复模型（208MB）

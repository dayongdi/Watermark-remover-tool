照片去水印工具 · 免安装版 v1.1
====================================

【怎么用】
1. 双击「照片去水印.exe」
2. 把照片拖进窗口（或点「打开照片…」）
3. 点「识别并标红水印」→ 检查红色区域（多涂的用橡皮擦、漏的用画笔补）
4. 点「开始去水印」
5. 点「保存结果…」

【重要】
· 必须把 models 文件夹和 exe 放在一起，AI 修复才能用。
· 首次修复要加载模型，会慢几秒；之后每张约 2~10 秒。
· 全部处理在本机完成，不联网、不上传任何图片。
· 杀软可能对未签名 exe 报警，属常见误报，加信任即可。

【操作】
左键涂抹 / 右键单击切换画笔橡皮 / 右键拖动平移 / 滚轮缩放
按住空格 对比原图 / Ctrl+Z 撤销一笔 / Esc 清空 / [ ] 调画笔大小

【可选设置】
· 「高清分块修复」默认开启：按原始分辨率处理，比缩放到 512 清晰得多。
  关掉会快一些，但修复区会变糊，一般不用关。
· 模型下拉：标准 512（默认，纹理最锐利）/ 大区域 1024（整块大 Logo、
  色块的结构更稳，纹理略平滑、慢约 70%）。
· 边缘外扩：水印去完还留一圈淡边时调大（3~6）。
· 接缝羽化：出现明显接缝时调大。

【环境要求】
Windows 10 / 11，64 位系统。无需安装 Python，无需管理员权限。

【想要更快的 GPU 加速？】
exe 版为控制体积走 CPU 推理。想要 17 倍加速请用源码版：
    https://github.com/dayongdi/Watermark-remover-tool
